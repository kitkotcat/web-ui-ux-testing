# Доказательства тестирования «Подобрать страну»

Папка предназначена для безопасного хранения доказательств, связанных с тестированием веб-квиза.

## Допустимые материалы

Можно добавлять:

- скриншоты воспроизведённых дефектов;
- скриншоты адаптивного режима Chrome DevTools;
- изображения некорректных рекомендаций;
- скриншоты выбранных одновременно вариантов «Да» и «Нет»;
- изображения UI и hover-дефектов;
- короткие обезличенные записи экрана.

## Проверка перед публикацией

Перед добавлением каждого файла необходимо проверить отсутствие:

- паролей;
- email-адресов;
- персональных данных;
- cookies;
- токенов авторизации;
- API-ключей;
- истории браузера;
- посторонних вкладок;
- приватных URL;
- конфиденциальных материалов.

## Правила репозитория

- скриншот должен подтверждать конкретный Bug ID;
- изображение следует обрезать до значимой области;
- персональные данные необходимо скрывать;
- HAR-файлы не публикуются;
- крупные видео не добавляются в Git;
- исходные изображения из старой таблицы не публикуются без дополнительной проверки;
- доказательства не должны содержать материалы, не относящиеся к проекту.

## Текущий статус

Публичные скриншоты пока не добавлены.

Основные фактические результаты и связи с Bug ID зафиксированы в Excel-отчёте.
