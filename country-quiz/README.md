# Тестирование веб-квиза «Подобрать страну»

Практический проект по ручному тестированию веб-квиза, который формирует рекомендации стран на основании ответов пользователя.

Проект демонстрирует функциональное, UI/UX, адаптивное, негативное и accessibility-ориентированное тестирование.

## Объект тестирования

| Параметр | Значение |
|---|---|
| Приложение | Веб-квиз «Подобрать страну» |
| Платформа | Web |
| Подход | Ручное black-box тестирование |
| Браузер | Google Chrome |
| Инструменты | Chrome DevTools |
| Операционная система | macOS 26.4, сборка 25E246 |
| Основной язык отчёта | Русский |

## Область тестирования

Проверялись:

- отображение заголовков, вопросов и элементов управления;
- логика рекомендаций стран;
- различные комбинации профессии, дохода и предпочтения моря;
- граничные сценарии;
- успешная отправка заполненного квиза;
- взаимоисключающий выбор вариантов «Да» и «Нет»;
- навигация с помощью клавиатуры;
- hover-эффекты;
- переход на страницу квиза из главного меню;
- адаптивность при ширине экрана 320 px.

## Основные найденные дефекты

### CQ-BUG-001 — орфографическая ошибка в заголовке

В заголовке квиза отображается текст «ПодАбрать страну».

### CQ-BUG-002 — некорректная логика рекомендаций

Разные комбинации ответов возвращают одинаковые или нерелевантные результаты. Среди рекомендаций также отображается Лондон, который является городом, а не страной.

Один корневой баг связан с шестью тестовыми комбинациями.

### CQ-BUG-003 — отсутствие корректной адаптации при 320 px

Плашки с вариантами ответов и элементы формы выходят за границы области просмотра.

### CQ-BUG-004 — отсутствует ожидаемый hover-эффект

Интерактивные элементы не всегда предоставляют понятную визуальную обратную связь при наведении курсора.

### CQ-BUG-005 — одновременно выбираются «Да» и «Нет»

Взаимоисключающие варианты ответа о море могут оставаться выбранными одновременно.

## Что было исправлено при подготовке отчёта

- сохранены все 13 исходных тестовых сценариев;
- добавлены последовательные ID `CQ-TC-001` — `CQ-TC-013`;
- исходные ID сохранены для трассировки;
- повторяющиеся баги логики объединены в один корневой дефект;
- исправлен противоречивый статус hover-теста;
- скорректирована критичность дефектов;
- унифицированы шаги, статусы и формулировки результатов;
- добавлена матрица трассировки;
- добавлены ограничения и примечания QA-ревью;
- встроенные изображения исходника исключены из публичной версии.

## Ограничения

- дата тестирования не была зафиксирована в исходной таблице;
- ожидаемые рекомендации основаны на исходной тестовой документации;
- исходный код приложения недоступен;
- тестирование проводилось методом black-box;
- полная кросс-браузерная проверка не выполнялась;
- адаптивность проверялась только на ширине 320 px;
- исходные встроенные изображения не публикуются без отдельной проверки;
- тестовая страница может измениться или стать недоступной.

## Дисклеймер

Практический QA-проект подготовлен для демонстрации навыков ручного тестирования и оформления тестовой документации.

Проект не связан с разработчиками тестируемого приложения. Контент и визуальные материалы принадлежат соответствующим владельцам.
